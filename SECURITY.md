# Security Policy

## Supported Versions

Security updates and bug fixes are provided for the latest release of Vortex Desktop. Older versions are not patched retroactively; please update to the latest build.

| Version | Supported |
| :--- | :--- |
| Latest release (`1.2.x`) | Yes |
| Older versions | No |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub Issues.

Instead, submit a confidential report using GitHub's **[Private Vulnerability Reporting](https://github.com/hamzaiqbal35/vortex-releases/security/advisories/new)** on this repository.

Please include:
1. Affected Vortex version and operating system (Windows / Linux)
2. Step-by-step reproduction details or proof of concept
3. Expected vs. actual behavior

You can expect an acknowledgment within a few days, and confirmed issues will be patched in the next Vortex release.
