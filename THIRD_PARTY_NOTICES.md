# Third-Party Notices

This repository is the Vortex releases and issue-tracking repository. It does not contain the application source code or dependency manifests needed to identify and verify the complete set of third-party components and their license notices.

**A complete third-party notices inventory has not yet been published here.** This page is intentionally transparent about that gap; it is not a substitute for the notices required for any particular release. A release-specific inventory should be generated from the source and dependencies used to build that release and published with its downloadable artifacts.
